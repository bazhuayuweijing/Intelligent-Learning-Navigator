# 数据结构

数据结构是计算机存储、组织数据的方式，是算法的基础。

## 线性结构

### 数组
连续内存空间，支持随机访问（O(1)）。插入和删除需要移动元素（O(n)）。
适用于：频繁读取、少量修改的场景。

### 链表
非连续内存，通过指针链接。插入和删除灵活（O(1)），但随机访问需要遍历（O(n)）。
单向链表、双向链表、循环链表三种变体。

### 栈
先进后出（FILO）。只允许在栈顶操作（push/pop）。
应用：函数调用栈、表达式求值、括号匹配。

### 队列
先进先出（FIFO）。入队（enqueue）在队尾，出队（dequeue）在队头。
应用：任务调度、广度优先搜索、缓存淘汰。

## 树形结构

### 二叉树
每个节点最多有两个子节点。前序/中序/后序/层序四种遍历方式。

### 二叉搜索树（BST）
左子树所有节点值 < 根节点值 < 右子树所有节点值。
查找、插入、删除平均O(log n)。

### 平衡二叉树（AVL）
任意节点的左右子树高度差不超过1。自平衡的BST，保证查找效率。

## 哈希结构

### 哈希表
通过哈希函数将键映射到存储位置。平均O(1)的查找性能。
冲突解决：链地址法、开放地址法、再哈希法。
装载因子超过阈值时触发扩容（rehash）。

## 复杂度对比

| 结构 | 访问 | 查找 | 插入 | 删除 |
|------|------|------|------|------|
| 数组 | O(1) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(n) | O(1) | O(1) |
| 栈 | O(n) | O(n) | O(1) | O(1) |
| 队列 | O(n) | O(n) | O(1) | O(1) |
| 哈希表 | O(1) | O(n) | O(1) | O(1) |
| BST | O(log n) | O(log n) | O(log n) | O(log n) |
