# 微积分

微积分是研究变化率和累积量的数学分支。

## 极限

极限是微积分的基石。当x趋近a时函数f(x)趋近的值。
- 左极限、右极限：从不同方向趋近
- 无穷小与无穷大：趋近于0或无穷大
- 重要极限：lim(sin x/x)=1 (x→0)、lim(1+1/n)^n=e

## 导数

函数在某点的瞬时变化率，几何意义是切线斜率。

### 基本导数公式
- (xⁿ)' = n·xⁿ⁻¹
- (sin x)' = cos x、(cos x)' = -sin x
- (eˣ)' = eˣ、(ln x)' = 1/x

### 求导法则
- 和差法则：(u±v)' = u'±v'
- 乘积法则：(uv)' = u'v + uv'
- 商法则：(u/v)' = (u'v - uv')/v²
- 链式法则：dy/dx = dy/du · du/dx

### 应用
- 极值判定：f'(x)=0且f''(x)<0为极大值，f''(x)>0为极小值
- 凹凸性：f''(x)>0为凹，f''(x)<0为凸
- 洛必达法则：0/0或∞/∞型的极限计算
- 泰勒展开：用多项式逼近复杂函数

## 积分

微分的逆运算，几何意义是曲线下的面积。

### 不定积分
- ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n≠-1)
- ∫eˣdx = eˣ + C
- ∫(1/x)dx = ln|x| + C
- 分部积分法：∫u·dv = uv - ∫v·du
- 换元积分法：∫f(g(x))·g'(x)dx = ∫f(u)du

### 定积分
- 牛顿-莱布尼茨公式：∫ₐᵇ f(x)dx = F(b) - F(a)
- 几何应用：求面积、体积、弧长
- 物理应用：位移、功、压力

## 多元微积分

- 偏导数：固定其他变量对一个变量求导
- 梯度：各偏导数的向量，方向是函数增长最快的方向
- 拉格朗日乘数法：条件极值问题
- 重积分：二重和三重积分
