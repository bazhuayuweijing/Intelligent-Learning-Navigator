# 牛顿力学

经典力学的基础，描述宏观物体在低速条件下的运动规律。

## 牛顿三大定律

### 第一定律（惯性定律）
任何物体都保持静止或匀速直线运动状态，除非外力迫使它改变。
- 惯性：物体保持运动状态不变的性质
- 惯性参考系：牛顿定律成立的参考系

### 第二定律（F=ma）
物体的加速度与所受合外力成正比，与质量成反比。
- 力的矢量性：加速度方向与合外力方向相同
- 瞬时性：力和加速度同时存在、同时变化

### 第三定律（作用与反作用）
作用力与反作用力大小相等、方向相反，作用在同一直线上。
- 成对出现，同时产生、同时消失
- 作用在不同物体上，不抵消

## 力学量

### 功与能
- 功：W = F·s·cosθ
- 动能：Ek = ½mv²
- 势能：重力势能Ep = mgh，弹性势能Ep = ½kx²
- 机械能守恒：只有重力/弹力做功时，E不变

### 动量
- 动量：p = mv
- 冲量：I = F·Δt
- 动量定理：I = Δp
- 动量守恒：系统合外力为零时总动量不变

## 圆周运动与万有引力

### 圆周运动
- 向心加速度：a = v²/r = ω²r
- 向心力：F = mv²/r
- 角速度、周期、频率关系

### 万有引力
- F = G·m₁m₂/r²
- 重力加速度g随高度变化
- 天体运动：开普勒三定律
