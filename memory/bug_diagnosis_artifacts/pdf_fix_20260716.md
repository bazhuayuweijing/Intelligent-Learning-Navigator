# PDF导出修复记录 — 2026-07-16 00:21–00:30

## 问题
评估页面「导出评估报告(PDF)」按钮下载的PDF内容为空——六维评分表、摘要、建议等所有中文内容均缺失。

## 根因分析

### 第一阶段：fpdf2 + STHeiti TTC 文字不可见
- `fpdf2` (2.8.7) 在处理 `.ttc` (TrueType Collection) 字体时无法正确子集化。
- 日志显示 `morx NOT subset; don't know how to subset; dropped` —— Apple 专有的 morx 表不被 fpdf2 支持，子集化时丢弃了中文字形数据。
- 即使从 TTC 中提取出 TTF（通过 fonttools）并剥离 Apple 表（morx/feat/bsln），fpdf2 的 cmap 处理仍不生成正确的 CID 映射，导致输出 PDF 中文字形为空白/空格。
- 尝试方案：fonttools 转换 TTC→TTF、剥离 Apple 表、强制格式4 cmap —— 均失败。

### 第二阶段：切换 ReportLab
- `reportlab` 5.0.0 对 CJK TrueType 字体支持良好。
- 使用系统自带 `/Library/Fonts/Arial Unicode.ttf`（23MB，支持 CJK 字符集）。
- 生成内容流使用 ASCII85Decode + FlateDecode 双重编码。
- CMap 正确映射 245 个 CID→Unicode 对。
- 经解码验证，PDF 包含全部中文内容：标题、综合评分、6维评分（含条形图）、评估摘要、优势、薄弱项、建议、计划调整、资源推荐、行动建议。

## 修复内容
- 替换 `_find_chinese_font()` 为 `_find_chinese_font_path()`，返回单一字体路径
- 重写 `api_export_pdf()` 函数，从 fpdf2 切换为 ReportLab
- 使用 `SimpleDocTemplate` + `Paragraph` + 自定义 `BarChart` Flowable
- 保留 `Content-Disposition` RFC 5987 头（中文文件名）
