# A3智学领航 - 部署说明书

## 环境要求

| 组件 | 最低要求 | 推荐配置 |
|------|---------|---------|
| Python | 3.10+ | 3.11 |
| 内存 | 512MB | 1GB+ |
| 磁盘 | 500MB | 1GB |
| 网络 | 可访问讯飞星火API、火山引擎API（非必需，DEMO_MODE可离线运行） |
| 浏览器 | Chrome/Firefox/Edge | 最新稳定版 |

## 配置准备（.env 文件）

项目根目录创建 `.env` 文件（参考 `.env.example`），配置外部服务密钥：

```bash
# ===== Flask =====
SECRET_KEY=your-secret-key
FLASK_ENV=production
PORT=5000

# ===== 运行模式 =====
# true = 降级模式（无API密钥也能完整演示，LLM调用自动使用模板回退）
# false = 完整模式（调用真实LLM/视频API）
DEMO_MODE=false

# ===== 讯飞星火大模型（LLM核心推理） =====
SPARK_APPID=your_spark_appid
SPARK_API_KEY=your_spark_api_key
SPARK_API_SECRET=your_spark_api_secret
SPARK_API_PASSWORD=your_spark_api_password

# ===== 讯飞语音识别（STT，可选） =====
STT_APPID=your_stt_appid
STT_API_KEY=your_stt_api_key
STT_API_SECRET=your_stt_api_secret

# ===== 火山引擎（AI视频生成，可选） =====
# 获取密钥：https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey
ARK_API_KEY=your_ark_api_key
# 视频模型（默认doubao-seedance，可用环境变量覆盖）
# VOLC_VIDEO_MODEL=doubao-seedance-1-0-pro-250528
```

> ⚠️ 视频生成API不可用时系统自动降级：仍可生成AI视频脚本（分镜/配音稿/字幕），不影响演示。

## 部署方式一：Docker容器化部署（推荐）

### 前置条件

- 已安装 Docker Engine 20.10+ 和 Docker Compose 2.0+

### 步骤

```bash
# 1. 进入项目目录
cd a3-智学领航

# 2. 准备.env文件（见上方配置准备）

# 3. 构建并启动
docker-compose up -d --build

# 4. 查看运行状态
docker-compose ps
docker-compose logs -f

# 5. 访问系统
# 浏览器打开 http://localhost:5000
```

### Dockerfile（实际）

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装系统依赖（fpdf2 + STT websocket）
RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# 安装Python依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制项目代码
COPY . .

# 暴露端口
EXPOSE 5000

# 启动命令（gunicorn生产级）
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "2", "--timeout", "120", "app:app"]
```

### docker-compose.yml（实际）

```yaml
version: '3.8'
services:
  web:
    build: .
    ports:
      - "5000:5000"
    volumes:
      - ./instance:/app/instance
    env_file:
      - .env
    environment:
      - FLASK_ENV=production
      - PORT=5000
    restart: unless-stopped
```

## 部署方式二：直接运行（MacOS/Linux）

### 前置条件

- Python 3.10+
- pip包管理器

### 步骤

```bash
# 1. 进入项目目录
cd a3-智学领航

# 2. 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置环境变量（可选，见上方.env说明）
export DEMO_MODE=true
export SECRET_KEY=your-secret-key
# （不配置API密钥则以DEMO_MODE运行，所有功能可用无需外部API）

# 5. 启动服务
python app.py

# 6. 访问
# 浏览器打开 http://127.0.0.1:5000
```

## 配置说明

### 环境变量表

| 变量名 | 说明 | 默认值 | 生产建议 |
|--------|------|--------|---------|
| `DEMO_MODE` | 启用降级（无API也可运行） | `true` | `false` |
| `SECRET_KEY` | Flask密钥 | 内置默认 | 设为复杂随机串 |
| `PORT` | 服务端口 | `5000` | 按需 |
| `SPARK_APPID` | 讯飞星火APPID | 空 | 完整模式必填 |
| `SPARK_API_KEY` | 讯飞星火API Key | 空 | 完整模式必填 |
| `SPARK_API_SECRET` | 讯飞星火API Secret | 空 | 完整模式必填 |
| `SPARK_API_PASSWORD` | 讯飞星火API Password | 空 | 完整模式必填 |
| `STT_APPID` | 讯飞语音APPID | 空 | 语音输入时必填 |
| `STT_API_KEY` | 讯飞语音API Key | 空 | 语音输入时必填 |
| `STT_API_SECRET` | 讯飞语音API Secret | 空 | 语音输入时必填 |
| `ARK_API_KEY` | 火山方舟API Key（视频生成） | 空 | 视频生成时必填 |
| `VOLC_VIDEO_MODEL` | 豆包视频生成模型 | `doubao-seedance-1-0-pro-250528` | 按需升级 |

### DEMO_MODE行为说明

DEMO_MODE下系统运行检测全链路，但所有LLM调用自动降级为模板内容，具体行为：

| 功能 | DEMO_MODE行为 | 完整模式行为 |
|------|--------------|-------------|
| 用户注册/登录 | 正常执行 | 正常执行 |
| 画像构建 | 规则解析回退生成8维画像 | LLM驱动对话画像 |
| 资源生成 | 8个Agent全部使用fallback模板 | LLM调用+模板回退 |
| 评估报告 | 规则评分引擎（含权重计算） | LLMEvaluator+规则 |
| 安全审核 | 白名单+敏感词 | 额外LLM幻觉检测 |
| 智能辅导 | 规则应答+模板对话 | LLM驱动苏格拉底式 |
| AI视频生成 | 仅生成视频脚本（无API调用） | LLM脚本+火山引擎出片 |
| 反馈回路 | 完整逻辑可用 | 完整逻辑+LLM增强 |

## 数据持久化

运行数据存储在 `data/learning.db`（SQLite文件）。它包含：

- 用户信息（User表，含教师/管理员角色）
- 画像数据（ProfileConversation表）
- 生成资源（GeneratedResource表）
- 评估报告（Evaluation/EvaluationReport表）
- 辅导会话（TutorSession表）
- 学习计划（LearningPlan表）
- 学习行为日志（LearningBehavior表）
- 安全日志（ContentSafetyLog表）
- 错题本（WrongQuestion表）
- 知识点掌握（KnowledgePoint表）
- 异步任务（AsyncTask表，视频生成任务）

**备份和迁移**：直接拷贝 `data/learning.db` 即可迁移所有数据。

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 端口5000被占用 | 其他服务 | 修改.env中PORT参数或kill占用进程 |
| `ModuleNotFoundError` | 依赖缺失 | `pip install -r requirements.txt` |
| 数据库错误 | 迁移未完成 | 删除data/learning.db后重启 |
| 启动后页面白屏 | 模板加载错误 | 检查浏览器控制台，确保templates目录完整 |
| Docker构建失败 | pip源慢 | Dockerfile中加 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` |
| 页面排版错乱 | Bootstrap未加载 | 检查网络（Bootstrap通过CDN加载），或切国内源 |
| 视频生成失败 | ARK_API_KEY未配置/欠费 | 检查.env配置，或保持DEMO_MODE（自动降级为脚本生成） |
| LLM返回空 | 星火密钥失效 | 检查SPARK_*四项配置，系统自动回退模板 |
| PDF导出乱码 | 系统中文字体缺失 | 安装中文字体（如Noto Sans CJK），代码自动查找字体路径 |
