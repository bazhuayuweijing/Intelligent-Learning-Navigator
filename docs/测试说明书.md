## 2. 集成测试

### 2.1 全链路流程测试

```
注册 → 登录 → 画像构建 → 资源生成 → 查看结果 → 辅导提问 → 评估 → 错题记录 → 复习提醒

```
python3 perf_test.py

输出验证：
- 注册成功：返回重定向到首页
- 登录成功：session正常
- 画像创建：ProfileConversation.is_complete = true
- 资源生成：8种Agent全部返回非空结果
- 辅导响应：TutorSession.is_active = true
- 评估报告：5个维度全部有分数
- 错题记录：WrongQuestion入库
- 记忆温度：温度状态正确返回
```

### 2.2 异常路径测试

| 场景 | 操作 | 预期 |
|------|------|------|
| LLM超时 | 配置超时=0.1s | 降级到模板内容，不崩溃 |
| 数据库断开 | 删除数据库文件后重启 | 自动创建新数据库 |
| 无画像用户 | 未画像直接请求资源 | 返回通用内容，不报错 |
| 重复注册 | 同一用户名注册两次 | 提示用户名已存在 |
| 恶意参数 | 注入特殊字符 | 参数校验拦截 |
| 视频API不可用 | 密钥缺失/网络断开 | 降级为仅脚本生成 |
| 教师权限越权 | 学生访问教师接口 | 403拒绝 |
